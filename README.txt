СМЕНА — УЧЁТ РАБОЧЕГО ВРЕМЕНИ

Запуск без установки:
Откройте dist/index.html двойным щелчком в современном браузере.
Для одинакового поведения localStorage во всех браузерах рекомендуется локальный сервер:
  node server.cjs
Затем откройте http://127.0.0.1:4173

Файлы:
  dist/index.html     — разметка, навигация и диалоговые окна
  dist/css/style.css  — оформление, фон и адаптивная версия
  dist/js/storage.js — хранение данных и расчёт рабочего времени
  dist/js/app.js     — события кнопок, вывод данных и CSV-отчёты
  tests/storage.test.cjs — тесты расчётов, запускаются node --test tests/storage.test.cjs

Возможности:
Начало смены, несколько перерывов, продолжение и завершение смены.
Обновление страницы и закрытие вкладки не прерывают смену.
История с фильтрами, график недели, отчёты по месяцам и экспорт CSV.
Редактирование профиля; примеры смен добавляются кнопкой «Демо-данные».

Принцип работы:
Храним время событий в миллисекундах, а не значение таймера.
Рабочее время = длительность смены минус суммарная длительность перерывов.
Смены через полночь распределяются по фактическим дням при подсчёте статистики.
Ключ хранилища: smena.state.v1. Данные отдельны для каждого браузера и адреса сайта.
Очистка данных браузера удаляет записи; CSV позволяет сохранить отчёт отдельно.

Это учебное приложение одного сотрудника без сервера и настоящей авторизации.
Для общей базы нескольких сотрудников потребуется сервер и база данных.
Ограничение: приложение использует часы устройства; вручную изменять время во время смены не следует.
